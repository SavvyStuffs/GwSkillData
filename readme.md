## https://bookahapp.com

This repo holds the updated and maintained skills_data.json and high res skill icons, as well as the monster zone data used in Bookah. There may still be some skill tags that are not perfect, but the values and descriptions are accurate.

I included skill_editor.py as well in case you dont want to wait for me to update this. Search for the skill, update the description if necessary, add the 0 and 15 att values from the description and lerp to your heart's content. It's a quick and dirty script from Gemini, double check the changes if you use it.
